- templates/
  - spack_hdnt.docx
  - spack_hdmb.docx
  - spack_ddh.docx
  - spack_bbbg.docx

  - swift_hdnt.docx
  - swift_hdmb.docx
  - swift_ddh.docx
  - swift_bbbg.docx

Cách đưa lên GitHub:
1. Upload index.html và nguyên thư mục templates vào root repository.
2. GitHub Settings > Pages > Deploy from a branch > main > /(root).
3. Không đổi tên các file trong templates nếu chưa sửa templateMap trong index.html.

Lưu ý:
- SWIFT hiện chưa có Mẫu 05 BBCC vì chưa có file Word mẫu SWIFT BBCC trong bộ file đã cung cấp.
- Các mục màu vàng trong giao diện HTML tương ứng với các nội dung từng được bôi vàng trong Word và có thể sửa trước khi xuất.
- Nút Xuất Word dùng đúng mẫu đang chọn. Nút Xuất PO dùng mẫu Đơn đặt hàng của công ty đang chọn.
